# Golden Years

适用于 Windows 10/11 的本地照片和视频整理工具。选择主文件夹并点击“执行”，程序会实际移动其中第一层受支持的媒体文件。整理期间请让其他程序暂停写入文件或改变目录结构。

## 安装与启动

安装 Python 3.11 或以上版本后，在仓库根目录执行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

唯一第三方依赖为 PySide6。应用使用根目录的 Golden_Years.ico 作为窗口和任务栏图标。缺少图标时仍可启动。

## 整理结果

按本机时区解释文件最后修改时间。例如，2026 年 2 月的照片会移入 `2026年/2月/Photos/MQP202602_01.jpg`，视频使用 `Videos/MQV202602_01.mov`。保留原后缀和修改时间。每月照片和视频分别从已有最大编号续排。本批文件按修改时间排序，同一时间按原文件名稳定排序。

程序对正式归档目录和本次新增媒体统一查重，依次比较大小、分块 SHA-256 和实际字节。已有归档件优先保留。本批新增件互相重复时保留排序最早的一件。其余移入 `XXX`，遇同名追加 `_1`、`_2` 等。每次成功转移重复件后，在 `XXX/YYYYMM_重复文件日志.txt` 中追加一行 UTF-8 JSON，年月取自执行日期。再次执行且无新增媒体时，已有归档与日志保持原样。

## 测试及限制

在仓库根目录运行：

```powershell
python -m unittest -v
```

已在 Linux 上用 Qt 离屏模式运行 8 项自动化测试，媒体均由临时目录生成。覆盖分类、排序、续号、重复件与日志、时间戳、冲突和权限错误、链接、分块校验、模拟跨卷移动，以及窗口选择目录、图标、后台执行和按钮状态。Windows 原生任务栏外观、真实文件占用及物理跨卷设备尚待实机验证。

同卷使用拒绝覆盖的移动操作。跨卷先写入目标目录中的独立 .partial 文件，校验内容和恢复时间戳后才发布目标并移除源文件。中断或磁盘异常可能留下临时副本或同时保留源与目标，请按界面中的路径检查。程序会跳过链接，对文件变化和写日志失败给出错误提示。扫描和移动之间无法锁定整个目录树，请勿同时在同一目录运行多个实例。
